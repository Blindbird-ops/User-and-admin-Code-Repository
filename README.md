# User and Admin Application

This repository contains the Flutter code for both the User and Admin sides of the application.

### Folders:
* **`admin_window`** - Contains the Dart/Flutter code for the Admin Dashboard. (Main code is in `admin_window/lib/main.dart`)
* **`mabs`** - Contains the Dart/Flutter code for the User Mobile App. (Main code is in `user_window/lib/main.dart`)bs
